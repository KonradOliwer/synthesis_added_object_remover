# Static methods and local functions of this module that mention no domain type (Ids or a Contracts type), each with its reason.
# Form: Type.Member | reason  (local function: Type.Method.Local). The test fails when an entry stops being flagged.
CsvReportOutput.Warning | Report wording: builds the warning text for a failed report file from the folder and the exception.
Describe.Cell | Report wording: labels a cell fact (a plugin-facts type outside the domain list).
Describe.Space | Report wording: labels a space fact (a plugin-facts type outside the domain list).
KeepReasonText.Relation | Report wording: names a link relation.
LogSections.AlsoRemoveMeshes | Report wording: prints mesh statistics (a tool's statistics type).
LogSections.AlsoRemovePairs | Report wording: prints mesh-pair statistics (a tool's statistics type).
LogSections.JoinOrNone | Report wording: joins names or prints "(none)".
UnexpectedErrorLines.InGroupOrder | Report ordering: sorts error records by part, failure and subject (an error record, not a domain type).
UnexpectedErrorLines.GroupLine | Report wording: the line of one group of unexpected errors (an error record, not a domain type).
Tables.ComponentFields | Report layout: the csv fields of one touching-chain row (a report row type, not a contract).
Tables.CountByComponent | Report counting: how many targets each touching chain holds; plain integers.
Tables.DescribeSeedReasons | Report wording: joins the seed reasons of a chain (a tool's table type).
