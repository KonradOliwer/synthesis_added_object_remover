# Static methods and local functions of this module that mention no domain type (Ids or a Contracts type), each with its reason.
# Form: Type.Member | reason  (local function: Type.Method.Local). The test fails when an entry stops being flagged.
SettingsFailureMessage.Compose | Wording for a settings file failure: joins the setting, the value found and what is allowed.
SettingsFailureMessage.DescribeLocation | Wording for a settings file failure: names where the value sits.
SettingsFailureMessage.ExtractFoundValue | Wording for a settings file failure: the value found in the exception text.
SettingsFailureMessage.LocationOf | Wording for a settings file failure: the location of the bad value.
SettingsFailureMessage.PathOf | Wording for a settings file failure: the settings file path of the bad value.
SettingsTree.ElementTypeOrSelf | The element type of a list setting.
ConfigFolders.GroupsFolder | Where the group files are looked for under the data folder.
ConfigFolders.ConfigsFolder | Where the config files are looked for under the data folder.
ConfigFolders.IsFileName | Tells a name a group file or the settings may give a config file by: Windows keeps it as written, so the config's report folder can be named after it.
ConfigFolders.FileNameOf | Adds the .json extension to a name written without it.
ConfigNotes.IsList | Tells a list setting from a single value.
ConfigNotes.ItemsOf | The items of a list setting, none for a null list.
ConfigNotes.DiffersFromDefault | Compares a setting's read value with its default.
JsonFileParsing.ReadText | Reads a group or config file and explains an unreadable one with the file named.
JsonFileParsing.Parse | Parses a group or config file and explains a syntax error with the file named.
JsonFileParsing.DescribeKind | Wording for a failure: what kind of JSON value was found.
JsonFileParsing.LineOf | The line a JSON value starts on.
GroupFile.ConfigFileNamesOf | Reads the config file names a group file lists and checks each.
GroupFile.NotAListOfNames | Wording for a failure: the group file does not hold a list of names.
ConfigFiles.JsonSettingsLikeSynthesis | The JSON rules Synthesis reads settings.json by.
