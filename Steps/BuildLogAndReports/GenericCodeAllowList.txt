LogSections.DescribeAlreadyRemoved | Report wording: the "of them already removed on changed terrain" part of the too-close line; it takes only the count.
LogSections.DescribeRestoredOfFound | Report wording: the "of them restored" part of a step's found line; it takes only the count.
LogSections.AddRowsLine | Report wording: the "wrote N rows" line of a written report file (a CSV tool's table record, not a domain type).
LogSections.DescribePluginList | Report wording: prints where the game's plugin list was read from and how many listings it has (a plugin-facts type outside the domain list).
LogSections.OnOff | Report wording: prints a setting's switch as on or off.
LogSections.WhenAny | Report wording: one counted item of the write line, left out when its count is 0; it takes only the count and the words.
LogSections.CountOutcomes | Report wording: counts each outcome of a step's evaluations as "N outcome text" (a step's own outcome enum and text function are given in).
LogSections.OnWith | Report wording: prints a setting's switch as off, or as on with the detail that matters when it is on.
LogSections.JoinOrNone | Report wording: joins names or prints "(none)".
LogSections.TrustReasonLine | Report wording: one trust reason's line of described plugins, or no line when no plugin has that reason.
LogSections.OtherMasters | Report wording: a number of other masters, singular for 1.
LogSections.MeshFailureCounts | Report wording: the counts of the "Mesh failures" and "Mesh triangle failures" lines (a mesh tool's category, not a domain type).
LogSections.MeshProblemLinesInOrder | Report ordering: sorts the mesh problems by mesh, then by their worded line (a mesh tool's problem record, not a domain type).
MeshProblemText.Line | Report wording: the line of one mesh or archive problem (a mesh tool's problem record, not a domain type).
MeshProblemText.FooterRootLine | Report wording: the line of a footer root problem (a mesh tool's problem record, not a domain type).
MeshProblemText.ReadFailure | Report wording: why one mesh read failed (a mesh tool's failure record, not a domain type).
MeshProblemText.FailureCategory | Report wording: a mesh failure as the "Mesh failures" line counts it (a mesh tool's category, not a domain type).
MeshProblemText.InvalidCoordinatesText | Report wording: the invalid-coordinates text (a mesh tool's fact, not a domain type).
MeshProblemText.ShapeCountsText | Report wording: the shape counts of a mesh without geometry (a mesh tool's fact, not a domain type).
MeshProblemText.Required | Report check: a mesh fact the kind needs is present; a missing one is a bug.
RunPartText.Unknown | Report check: the bug exception for a part key without wording (a tool's key type, not a domain type).
Tables.CountByComponent | Report counting: how many targets each touching chain holds; plain integers.

Tables.PartNames | Report wording: the names of the parts of a placed record that are set (a tool's part type).
LogSections.FactLine | Report wording: "Heading: fact, fact." for the facts a count line states, or no line when there is none; it takes only words.
RestoreCountLines.Breakdown | Report wording: the "N name" items of a count line joined (the names are given in).

Tables.TableWhenAnyRow | Report columns: a CSV table, or none when it has no row (a CSV tool's table record, not a domain type).
